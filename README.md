# VDE-VLM-ACCESS
This repo is for LLM/VLM/NNs that can code for the VDE project, allowing them to connect to a Virtualbox VM and interact and see it with their own VFM (or as a text transcription). Please expect this to work with Gemini/Antigrav mostly as that is what VDE is coded with. Future support for Claude, GLM, Qwen, Codex, and local models coming soon \^=^/
